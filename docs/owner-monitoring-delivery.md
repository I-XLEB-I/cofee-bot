# Личные уведомления владельцу

Владелец выбрал личный чат основного кофе-бота. Для включения используется
`OWNER_MONITORING_ENABLED=true`. `OWNER_MONITORING_CHAT_ID` может явно выбрать
получателя из существующих редакторов выплат; без него допускается только один
такой пользователь. Backend дополнительно проверяет свой список владельцев.
Групповой ID или неоднозначный выбор останавливают запуск доставки.

Кофе-бот раз в пять минут получает события через существующее защищённое
соединение с backend. Используются результаты уже работающего мониторинга
Vendista, без новых обращений к модели или повторного опроса источника.
Устаревший снимок не выдаётся за текущее состояние. Пороги и правила
восстановления сохраняются; отсутствие продаж не объявляется поломкой.

Рядом с файлом состояния бота на существующем диске хранится
`owner_monitoring.sqlite3`: состояние точек, события, результаты доставки и
ID сообщений. Состояние и очередь записываются одной транзакцией; повтор
события и параллельная обработка не создают вторую отправку. Новая проблема
приходит сообщением, часовой повтор обновляет его, восстановление приходит
отдельно. Уже неактуальная проблема, которую ещё не отправляли, пропускается.

Если Telegram явно ограничил частоту, попытка откладывается. Потеря ответа
на отправку помечается `uncertain`, включая перезапуск в момент отправки:
автоматической повторной отправки нет, поскольку Telegram sendMessage не имеет
ключа идемпотентности. Такие записи требуют проверки журнала; безусловная
доставка ровно один раз не обещается. Чат поддержки backend остаётся отдельным
каналом и не включается этим переключателем.

Первый выпуск сохраняет одну основную проблему на точку. Автоматическая сверка
с Telemetron, подтверждение прочтения и отсрочка пользователем относятся к
следующему расширению. Модель и её бюджет не меняются.

Проверено локально: 119 тестов бота + 19 subtests, 1026 тестов backend;
внешняя сеть отключена. Рабочая доставка подтверждается отдельно после выпуска.

# Групповой технический помощник

Дата: 11.10.2026. Поток: ошибки кофейного аппарата и терминала.

## Решение владельца

Существующий coffee-bot, ответы по @упоминанию или ответу на сообщение бота.
На каждой точке один аппарат. Модели: [справочник](EQUIPMENT_REGISTRY.md).
Текст и фото; при серьёзной проблеме — черновик сообщения мастерам без автоотправки.

## Развёрнутая функциональность

- Отдельный технический endpoint с тем же списком сотрудников и лимитом ИИ.
- Групповой обработчик раньше учётных обработчиков: обычная переписка не идёт в ИИ,
  диагностические сообщения/их правки не записываются как обслуживание или товары.
- Изолированный контекст обращения по ответам на сообщения; смена точки очищает старый случай.
- Telemetron: состояние, время отчёта и до пяти событий за сегодня/вчера.
- Vendista: состояние/связь; при проблеме терминала последние события платежей за сегодня,
  без сумм, карт, RRN и персональных реквизитов. Недоступность явно показывается.
- Инструкции G23 / PRO LV307, официальная база Vendista; интернет-поиск Keenable с чтением новых страниц и ссылкой в ответе.
- Фото JPEG до 256 КБ передаётся байтами, без Telegram URL с токеном, без записи на диск.
- Домашний PRO LV307 не получает выдуманной телеметрии.
- При опасных симптомах — остановка эксплуатации и полный черновик сервису даже при сбое ИИ/неизвестной точке.
- Сервер фильтрует рекомендации модели: сотруднику только внешние проверки/фото, MDB/разборка/измерения — мастеру. Свежесть телеметрии показывается обязательной строкой.

## Ограничения

Интернет-поиск использует публичный API Keenable, доступный без новой подписки.
Бот различает отсутствие дополнительных публикаций, сбой провайдера, лимит запросов и
недоступный текст найденной страницы. При сбое поиска инструкции не теряются.
Инструкции и базы читаются напрямую, кешируются на 6 часов.
Контекст обращения хранится до 6 часов в памяти процесса (до 256 ответов); после перезапуска
остаётся цитата сообщения, а недостающие проверки нужно уточнить. Фото не сохраняются.
Модель Gemini 2.5 Flash-Lite и месячный лимит не меняются. До двух обращений к модели на вопрос
учитываются в существующем журнале ИИ и дневном лимите. Нет возвратов/команд терминалам.

# Справочник оборудования

Подтверждено владельцем: 11.10.2026. На каждой действующей торговой точке один кофейный аппарат.

| Место | Модель |
|---|---|
| Гиппо | Jofemar Bluetec G23 |
| Гагарина | Jofemar Bluetec G23 |
| Беломорский | Jofemar Bluetec G23 |
| Сити | Jofemar Bluetec G23 |
| Южный | PRO LV307 |
| Макси | PRO LV307 |
| Дома | PRO LV307 |

«Испанец» / «испанцы» означает Jofemar; «Pro lv» — PRO LV307.
Домашний аппарат не является торговой точкой; не приписывать ему ID Telemetron или Vendista.
Архивная точка «Беломорский китаец» не означает, что на Беломорском сейчас два аппарата.
Перед уточнениями модели сверяться с этим документом. При явной замене оборудования
обновлять и документ, и `point_registry.py` серверного проекта telemetron-mcp.

Групповой помощник: существующий coffee-bot, вызов по @упоминанию или ответу
на сообщение бота. При серьёзной неисправности готовит черновик обращения в
сервис; автоматически мастерам его не отправляет.
